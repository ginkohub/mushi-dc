## 4. Data Collection
The Bot stores the following data in a local JSON file:

- **User data:** Discord user ID, username, display name, role level, XP, language preference, AFK status, and message stats.

- **Block list and prefixes** are held in memory only and reset on restart.

No data is shared with third parties. Data is stored locally on the host machine.
